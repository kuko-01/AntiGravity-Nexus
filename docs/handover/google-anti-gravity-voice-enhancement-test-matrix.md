# テスト観点一覧（受け入れ基準付き）

更新日: 2026-02-20

## 1. 受け入れ基準（再掲）
1. 歌唱モードON時に、通常モード比で表現差分が聴感で判別可能。
2. 感情強度が会話ターンごとに急激に乱高下しない。
3. 破綻音（クリップ、過大ノイズ、波形欠損）が増加しない。

## 2. テストマトリクス

| ID | 区分 | ケース | 入力条件 | 期待結果 |
|---|---|---|---|---|
| UT-01 | 単体 | 感情強度クランプ | intensity=-0.3 / 1.7 | 0..1 に丸められる |
| UT-02 | 単体 | 感情ラベル不正値 | hint=`unknown` | `neutral` にフォールバック |
| UT-03 | 単体 | 歌唱モード判定 | 明示ON/OFF | ONで歌唱補正、OFFで通常補正 |
| UT-04 | 単体 | WAVヘッダ解析 | 正常WAV/壊れたWAV | 正常はメタ取得、壊れたWAVは失敗返却 |
| UT-05 | 単体 | 後処理フェイルセーフ | 後処理で例外 | 元音声が返る |
| UT-06 | 単体 | パラメータ境界 | vibratoDepth, rate, dynamic | 上限/下限で正しくクランプ |
| IT-01 | 結合 | `sbv2` モード | 通常会話文 | 音声生成成功、異常ログなし |
| IT-02 | 結合 | `sbv2+rvc` モード | 通常会話文 | 音声生成成功、`stages.totalMs` 記録 |

| AQ-04 | 聴感 | 楽/興奮 | 代表文4本 | 感情一致MOSが基準以上 |
| AQ-05 | 聴感 | 歌唱 | 代表文4本 | 通常との差分が判別可能 |

## 3. KPI測定方法

| 指標 | 定義 | 集計単位 | 閾値例 |
|---|---|---|---|
| 失敗率 | `voice.success=false` の比率 | 日次 | 2%未満 |
| 平均処理時間 | `stages.totalMs` の平均 | 日次/モード別 | 2500ms未満（目安） |
| MOS（自然さ） | 5段階主観評価 | 週次 | 3.8以上 |
| MOS（感情一致） | 5段階主観評価 | 週次 | 3.8以上 |

## 4. 検証データセット提案
- 合計20文（喜/怒/哀/楽/歌唱 各4文）
- 長文/短文比率: 1:1
- 感嘆符あり/なし比率: 1:1
- キャラごとの話法差分を含む文を最低2文/カテゴリ

## 5. テスト実施順序（推奨）
1. 単体テスト（クランプ、WAV解析、フェイルセーフ）
2. 結合テスト（3モード）
3. 回帰テスト（既存互換）
4. 聴感評価（20文）
5. KPI試験運用（限定公開）
